# Smart Content & API Generator Agent

An automated AI workflow tool that takes high-level user requirements and generates structured JSON API specs and Next.js UI code.

## Tech Stack
- **Languages & Frameworks**: Python, Next.js, TypeScript, Tailwind CSS
- **AI Integration**: LLM APIs (Claude / OpenAI), Claude Code / Cursor config
- **Testing & Tooling**: Playwright E2E testing, AGENTS.md project rules
- **Deployment**: Vercel / Cloud Host ready

## Project Structure
- `app/` - Next.js App Router UI & API endpoints
- `backend/` - Python API & prompt handler engine
- `tests/` - Playwright E2E automation scripts
- `AGENTS.md` - AI assistant coding rules & style guidelines
