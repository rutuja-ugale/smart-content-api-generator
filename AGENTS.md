# AGENTS.md - AI Coding Assistant Guidelines

## Code Style & Structure
- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS.
- **Backend / Scripts**: Python 3.10+, FastAPI or script-based API processing.
- **Component Styling**: Functional components with clean layout and responsive design.
- **Testing**: Playwright for end-to-end testing of UI flows and navigation.

## Repository Rules
1. Maintain strong TypeScript typing across all Next.js API routes and components.
2. Keep Python API models aligned with JSON Schema outputs.
3. Automated Playwright tests must be included in `tests/` to verify UI rendering.
